    Verification

    숫자는 손으로 옮기지 않는다

    이 사이트의 연구 수치는 build_data.py 가 data_raw/ 의 원자료에서 뽑아 data/*.json 으로 만든 것입니다. 원자료를 바꾸고 다시 실행하면 사이트가 따라 바뀝니다. 값이 없으면 추정하지 않고 DATA PENDING 으로 표시합니다.

    Reproduce (재현)

    모든 수치는 아래 명령으로 다시 만들 수 있습니다
    재현 정보 →
    # 1. 사이트 폴더로 이동 cd nexus # 2. 원자료 → data/*.json (표준 라이브러리만 사용) python3 build_data.py # 3. 커밋된 data/ 가 원자료와 같은지 확인 python3 build_data.py --check # 4. 테스트 (H1 계산식 원본 대조 · 숫자 하드코딩 검사) python3 -m unittest discover -s tests -v # 5. 로컬 미리보기 python3 -m http.server 8000
