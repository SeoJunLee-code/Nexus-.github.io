    Layer 1 · 누구나 읽는 설명
    무엇을 묻나

    AI 의 '자신감'으로 실패를 미리 알 수 있을까

    강화학습 에이전트는 매 순간 각 행동이 얼마나 좋을지 점수(Q 값)를 매깁니다. 그중 최댓값 maxQ 는 에이전트가 지금 상황을 얼마나 좋게 보는지에 가깝습니다.

    에이전트가 여러 배치(layout)의 환경에서 열쇠(key)에 도달하는 과제를 할 때, 처음 5걸음의 maxQ 만 보고 그 뒤 성공할지 맞힐 수 있는가? 맞힐 수 있다면 실패를 미리 감지하는 모니터로 쓸 수 있습니다. 해석

    어떻게 공정하게 재나

    열쇠에 가까이서 시작하면 당연히 성공하기 쉽습니다. 그래서 같은 배치·같은 거리끼리만 비교하는 층화 AUROC 를 씁니다 (0.5 = 우연, 1 = 완벽).

    Revisit / tautology analysis

    Phase 1d · Perturbation (confound control)

    교란 통제 — 층화 방식에 따라 신호가 얼마나 남나

    raw = 층화 없음 · dist = 거리 층 · layout = 배치 층 · lay×dist = 배치×거리 층. 거리(가까울수록↑) 자체가 얼마나 예측하는지와 나란히 봅니다.
