    How to read

    읽는 법

    AUROC

    0.5 = 우연, 1 = 완벽, 0 = 완벽하게 반대. Paper 5 의 AUROC 는 대부분 층화(같은 배치·거리 등끼리만 비교) 값이며, CI 는 run 군집 부트스트랩입니다 (원자료 ci95).

    Backfire · 비율

    H1 의 backfire 는 비축퇴 문제 중 다수결이 틀린 비율. CI 는 문제 단위 부트스트랩 B=10000, seed 0 (원본 코드 _boot 와 같은 방식, build_data.py 재계산).

    Source · Path

    path 는 원본 JSON 안의 위치, method 는 원자료에서 계산한 방법입니다. Evidence 버튼은 원본 파일 SHA-256 까지 보여 줍니다.

    Downloads

    데이터 파일

    h1v2_*.jsonl 원자료는 용량 때문에 저장소에 올리지 않았습니다 (SHA-256 만 기록). 문제별 집계는 data_raw/h1_problem_rows.json 에 있습니다.
